## Overview

`skillx` is the training and knowledge center of the ToolX ecosystem.

It turns raw knowledge into trusted, reusable skills that can evolve over time from external sources, project agents, and real engineering experience.

The core lifecycle is:

```text
Ingest → Clean → Normalize → Validate → Version → Score → Promote → Learn
```

SkillX is designed to keep agent knowledge reusable, traceable, testable, and continuously improvable instead of leaving valuable experience trapped inside individual sessions or projects.

## Core responsibilities

- Ingest skills and knowledge from trusted or untrusted external sources
- Extract reusable knowledge from agents working on real projects
- Clean and normalize imported content before it enters the registry
- Preserve provenance, attribution, metadata, and version history
- Validate skill structure, safety, compatibility, and expected behavior
- Score and promote stronger skill versions over weaker ones
- Detect duplicates, conflicts, regressions, and stale knowledge
- Feed verified skills back into agents and ToolX projects
- Learn from execution results and project feedback over time

## Principles

- **Skills are versioned knowledge, not disposable prompts.**
- **External content is untrusted until cleaned and validated.**
- **Every promoted skill should be traceable and testable.**
- **Project experience should improve the shared intelligence layer.**
- **Quality beats quantity.**
- **Agents consume trusted skills; they do not define truth by themselves.**
